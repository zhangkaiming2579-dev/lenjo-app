拍照识别热量与卡路里

拍一张餐食照片，可以先得到食物和营养估算，再检查份量、配料与油脂。热量、卡路里和大卡是用户常用的不同叫法；营养记录通常以 kcal 表示。

叫法与含义

拍照识别热量 / 拍照识别卡路里 / 拍照算热量
在饮食照片分析中估算一餐的能量；图片无法确定所有配料与实际重量。
食物识别 / 餐食识别 / AI识别食物
识别照片中的食物项目，用户可以纠正识别错的食物。
热量估算 / 卡路里估算 / 大卡估算
把识别出的食物与估计份量转换为营养参考值，确认后才写入记录。
拍照记录饮食 / 拍照记餐 / 餐食照片分析
用照片开始记录流程；可从相册选择餐食图片，分析后编辑并保存。

使用问题

这顿饭有多少卡路里？

拍照分析后先检查食物种类和份量，尤其是酱汁、烹调用油及照片外的食物，再确认估算。

可以从相册识别食物热量吗？

可以选择餐食图片做分析；光线和遮挡会影响结果，仍需核对后保存。

多人合餐怎么记录自己吃的份量？

餐食扫描支持合餐份量与同餐分项；按自己实际吃的部分检查并修改，避免把整桌算成一人的摄入。

饮食管理与营养素记录

饮食管理从可检查的记录开始：手动输入或拍照分析，确认热量、蛋白质、碳水和脂肪，再让教练结合训练讨论。

叫法与含义

饮食管理 / 饮食记录 / 饮食日记
按餐保存吃过的食物；不使用照片分析时，也能手动填写。
卡路里记录 / 热量记录 / 食物热量记录
记录摄入能量，与训练消耗分别看待。
蛋白质记录 / 蛋白摄入记录 / 蛋白质摄入管理
记录蛋白质估算或手动数值，为饮食与训练讨论提供依据。
三大营养素 / 宏量营养素记录 / 碳水脂肪记录
分别查看蛋白质、碳水化合物与脂肪；这些数值受食物和份量估算影响。

使用问题

不拍照也可以记饮食吗？

可以手动记录食物和营养数据，照片分析是可选入口。

能记录蛋白质、碳水和脂肪吗？

可以记录三大营养素，照片分析给出的是待核对估算值。

摄入卡路里和运动消耗卡路里是一回事吗？

两者分别是吃进去的能量与运动能量记录。练境保留饮食与训练信息，讨论时需注意数据来源和误差。

AI 饮食与营养讨论

AI 饮食建议以已记录的信息为依据。你可以说明体重目标、近期吃了什么及训练安排，讨论蛋白摄入和训练前后饮食。

叫法与含义

AI饮食 / AI饮食管理 / AI营养助手
在教练对话中结合饮食记录讨论下一步，建议需要用户判断与确认。
饮食分析 / 营养分析 / 餐食营养分析
将已确认的食物与营养记录用于讨论，信息不足时需补充。
减脂饮食记录 / 热量缺口参考 / 体重目标饮食
结合体重目标讨论摄入与活动；不能把单餐估算当成精确的全天能量平衡。
增肌饮食参考 / 训练前饮食 / 训练后饮食
结合力量训练和近期记录讨论补充什么；没有固定适用于每个人的食谱承诺。

使用问题

练境能做 AI 饮食管理吗？

支持手动饮食、照片估算和基于记录的教练讨论；先确认记录，再询问如何调整。

今天的蛋白质够不够？

先保存今天的饮食，并告诉教练体重目标和训练情况。建议的质量取决于记录完整程度。

减脂和增肌可以结合训练与饮食一起看吗？

可以把训练记录、饮食和体重目标放进同一次讨论，持续核对实际变化；练境不保证减重或增肌结果。

AI 健身与 AI 教练

练境把对话建议接到训练执行：说明条件、审核计划、记录实际完成情况，再用保存的结果讨论下一练。

叫法与含义

AI健身 / AI健身App / 智能健身助手
以训练目标和实际记录为上下文，提供健身参考与计划建议。
AI教练 / AI健身教练 / AI训练教练
在教练对话中请求动作、组数、次数、负荷和休息建议。
AI私教 / 智能私教 / 健身聊天助手
这些是对软件教练的常见叫法；练境不提供真人现场观察或医疗诊断。
个性化训练建议 / 根据历史安排训练 / 训练复盘对话
让教练参考已保存的训练和获准使用的恢复信息，解释下一次建议。

使用问题

AI 健身教练会参考我以前的训练吗？

可以参考已保存的训练记录与允许使用的信息；没保存、没提供或缺失的数据无法作为可靠依据。

AI 教练建议能直接变成训练计划吗？

结构化计划可审核、修改并进入训练，执行时填写真实完成情况。

可以只记录训练，不和 AI 聊天吗？

可以。iPhone 的训练执行与记录独立可用，AI 对话需联网、同意处理并受额度限制。

训练计划与健身安排

告诉教练你有哪些器械、练过什么、每周可练几天和单次时间。计划需要检查动作、组数、次数与重量，再开始执行。

叫法与含义

健身计划 / 训练计划 / AI训练计划
生成可以审核的结构化训练安排，并连接逐组记录。
力量训练计划 / 增肌训练计划 / 减脂训练安排
说明目标和条件后讨论力量训练；目标不等于效果保证。
每周训练安排 / 训练分化 / 分化训练计划
告诉教练自己的训练日和分化方式，作为后续计划讨论的上下文。
今日训练计划 / 下一次训练安排 / 训练计划调整
结合已有记录和当天条件讨论一次具体训练，必要时修改原建议。

使用问题

今天练什么？

说明可用时间、器械、最近训练和恢复感受，请教练安排，审核后开始。

每周只有三天怎么安排健身？

把每周可练天数、单次时长和目标告诉教练，请它解释安排理由，再按实际完成情况调整。

计划里的动作或重量能修改吗？

开始前可审核并修改动作、组数、次数和重量，训练时记录实际表现。

健身管理与逐组训练记录

训练管理包含计划和完成记录。目标重量与实际重量、计划次数与实际次数要分别看，保存的真实表现才能用于复盘。

叫法与含义

健身管理 / 训练管理 / 健身记录App
组织计划、执行和历史记录，在同一产品中回看。
训练记录 / 健身日志 / 训练日记
保存每场训练的动作和完成情况，便于后续比较。
逐组记录 / 重量次数记录 / RPE记录
每组填写实际重量、次数和用力感受，避免只保留一个完成标记。
自由训练 / 补记训练 / 历史训练文本导入
可以不先生成计划；也可补录已完成训练，或从粘贴文本导入历史记录并检查结果。

使用问题

可以记录每组重量和次数吗？

可以在 iPhone 逐组记录重量、次数及 RPE，结束后保存训练。

忘记记录的训练能补上吗？

可使用补记训练，把实际做过的训练写入历史，填写能确认的项目。

其他地方的训练文字能导入吗？

当前公开版本支持粘贴文本导入历史训练，包含有氧时间和距离；导入后需要核对内容。

力量进步与训练复盘

把已保存的重量、次数、RPE 与恢复感受一起看，再讨论加重、增加次数、维持或减量。

叫法与含义

力量训练记录 / 增肌训练记录 / 抗阻训练记录
记录抗阻训练的实际负荷和组数，为长期比较提供依据。
渐进超负荷 / 加重量建议 / 增加次数建议
用实际表现讨论是否提高训练负荷；不按固定比例自动替用户加重。
训练容量 / 训练量记录 / 训练负荷趋势
数据页回看训练量相关趋势，结合动作与时间范围理解。
训练复盘 / 训练报告 / 1RM参考估算
回看阶段表现与历史训练；1RM 为参考估算，不能视为实测极限重量。

使用问题

下一次应该加重量还是加次数？

保存这次的实际重量、次数、RPE 和恢复感受，要求教练解释建议及下次检查什么。

可以回看一个月的训练量吗？

数据页有训练趋势、月历和报告；结论取决于是否完整保存了训练。

1RM 数值是实测的吗？

训练数据中的 1RM 是参考估算，需要结合动作、记录质量和个人状态理解。

新手、居家与有限时间训练

条件说得越清楚，建议越容易检查。告诉教练是健身房还是居家，有无哑铃，以及可用时间和经验。

叫法与含义

新手健身计划 / 健身入门安排 / 初学者力量训练
从个人经验和器械条件出发请求计划，训练时量力执行。
居家健身计划 / 家庭训练安排 / 在家力量训练
把家中场地和可用器械告诉教练，避免计划引用没有的设备。
哑铃训练计划 / 自重训练安排 / 无器械训练建议
说明实际器械限制，检查推荐动作是否适合自己；不意味着所有动作均有视频教学。
短时训练计划 / 30分钟健身安排 / 时间有限健身
把本次时间作为约束，请教练安排可审核的一次训练。

使用问题

健身新手不知道怎么排计划怎么办？

告诉教练经验、目标、器械和时长，请它说明动作选择和组次，再检查能否执行。

只有哑铃能用练境吗？

可以把哑铃作为器械条件请求计划，并使用 iPhone 记录实际训练。

只有半小时也能安排训练吗？

可以明确今天只有半小时；执行前检查计划总时长与休息安排是否合适。

Apple Watch 腕上训练

Apple Watch 训练是可选 Pro 功能。需要配对手表、安装练境 Watch App，并允许所需健康数据；iPhone 可独立记录。

叫法与含义

Apple Watch健身 / Apple Watch力量训练 / 苹果手表健身记录
在已配对的手表上执行训练计划，完成结果同步回 iPhone。
手表训练计划 / 腕上训练 / 手表逐组记录
查看计划并记录每组实际次数、重量和完成情况。
实时心率训练 / 逐组心率 / 心率训练时间轴
有授权和可用采样时，将心率与训练组的时间对应。
手表组间休息 / 恢复震动提醒 / 腕上恢复参考
组间查看恢复信息，满足条件时用震动提示下一组；不保证每次都有完整信号。

使用问题

Apple Watch 能记录力量训练的每一组吗？

Pro 用户可在腕上执行与记录，需安装配对的 Watch App；实际次数可修正。

手表会自动识别动作次数吗？

当前不自动识别动作次数，次数由目标值预填，再由用户按实际完成情况修正。

没有 Apple Watch 还能用吗？

可以在 iPhone 独立执行、逐组记录并保存训练，手表不是前提。

训练恢复与组间休息

恢复参考需要数据，也需要你的实际感受。健康数据仅在允许且可用时参与训练讨论，不能独立判断动作质量或医学状态。

叫法与含义

组间恢复 / 组间休息 / 下一组开始参考
结合实时心率、已休时间和训练信号讨论下一组节奏。
心率恢复 / 心率下降 / 恢复就绪参考
在信号可用时提供健身节奏参考；没有临床诊断含义。
睡眠与训练 / HRV训练参考 / 静息心率与训练
获准且可用的健康信息可作为教练上下文，需要结合历史与实际感受。
恢复状态记录 / 疲劳训练调整 / 减量训练讨论
描述疲劳和近期完成情况，请求较保守的训练调整并检查理由。

使用问题

组间要休息多久？

可参考计划休息与 Watch 恢复提示，同时结合自身感受；不适时不要仅凭提示继续。

昨晚没睡好，今天训练怎么改？

告诉教练睡眠和体感，结合已保存训练及允许使用的数据讨论减量或调整。

没有心率或 HRV 数据还能训练吗？

可以。缺少健康数据时仍能记录训练和主观感受，不应把缺失数据当作正常结果。

有氧计时与运动消耗记录

有氧使用时间、速度、坡度和距离等信息描述。手表记录的心率、热量与距离取决于设备、运动类型及可用数据。

叫法与含义

有氧训练记录 / 有氧计时 / 有氧健身管理
按时间记录有氧段落，用实际持续时间描述训练。
跑步机训练记录 / 坡度走记录 / 速度坡度记录
对相关项目填写速度、坡度和距离，区分手动输入与设备数据。
运动热量记录 / 训练卡路里记录 / 运动消耗参考
Pro 手表训练可保留可用的消耗数据，属于设备估算参考。
有氧时长记录 / 运动距离记录 / 力量有氧组合记录
在训练记录中保留有氧时长与相关距离，并与力量训练一起回看。

使用问题

跑步机的坡度和速度能记录吗？

可以为相关有氧项目填写速度、坡度和距离，核对单位与实际器械数据。

能看训练消耗的卡路里吗？

Pro 手表训练在数据可用时能记录热量；应理解为设备估算，而非精确能量测量。

力量训练和有氧可以一起记录吗？

练境支持逐组力量记录和按时间的有氧记录，回看时按实际训练类型理解数据。

体重、训练日历与阶段趋势

趋势来自持续记录。把体重、训练日历和训练表现放在一起回看，单日波动或一张照片不能证明长期效果。

叫法与含义

体重管理 / 体重记录 / 体重趋势
保存可确认的体重并回看变化，教练可以结合目标讨论。
健身进度记录 / 训练趋势 / 阶段训练总结
用已保存的历史观察训练频率和表现变化。
训练日历 / 健身月历 / 训练天数统计
回看计划、已完成训练和训练天数，计划不等于实际完成。
活动趋势 / 身体数据记录 / 恢复趋势
对可用记录和获准健康数据进行回看，来源与缺失情况需要区分。

使用问题

体重变化可以和训练记录一起看吗？

可以回看体重与训练趋势，再让教练基于保存的数据讨论目标和下一步。

训练日历能看到过去练了几天吗？

训练月历与天数统计来自保存的训练，未完成计划需要与已完成记录区分。

能保证减脂或练出肌肉吗？

不能保证。练境提供记录、计划与参考建议，结果还受到执行、饮食、恢复和个人情况影响。

器械识别与体测报告识别

照片分析还可用于健身器械和体测报告。器械候选、动作候选和报告数据都需要检查，不能将识别结果当作确定事实。

叫法与含义

健身器械识别 / 拍照识别器械 / AI器械识别
给出候选器械，用户确认后再用于训练安排。
器械动作候选 / 器械训练建议 / 根据器械安排训练
围绕确认的器械讨论可用动作；不是摄像头实时纠正动作。
体测报告识别 / 拍照读体测报告 / 身体成分报告识别
从报告照片提取身体数据，逐项核对数值与单位。

可以拍照导入体测报告吗？

可以分析报告照片并转成身体数据，检查项目、数值与单位后确认。

能实时识别动作是否标准吗？

当前公开功能未提供实时动作纠正。器械识别给出候选，实际动作质量不能只靠器械照片判断。

没有网络还能记录健身吗？
